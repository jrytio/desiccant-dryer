# PCB Design in KiCad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One fab-assembled KiCad 10 board, generated from Python in `hardware/`, that replaces the two protoboards, with ERC, DRC (including a 6 mm mains clearance rule) and fab exports run by `scripts/hardware.sh` locally and in CI.

**Architecture:** `hardware/dryer_board/circuit.py` is the single table of parts, pins and nets; everything else derives from it. `schematic.py` writes a label-style `.kicad_sch` by embedding stock symbols; `board.py` builds the `.kicad_pcb` through KiCad's bundled `pcbnew` Python from a placement table and exports a DSN; `route.py` runs Freerouting in Docker and imports the SES; `kicad-cli` checks and exports. The committed KiCad files are regenerated by the generator and compared in CI; routing stays local.

**Deviation from the spec:** exports are driven by `export.py` calling `kicad-cli` directly instead of a `.kicad_jobset`; same commands, no GUI-authored JSON to maintain.

**Tech Stack:** KiCad 10.0.6 (`kicad-cli`, bundled Python 3.9 with `pcbnew`), Docker image `ghcr.io/freerouting/freerouting:2.5.0`, CI image `kicad/kicad:10.0`, Python 3.9 standard library only (no pip), bash.

**Spec:** `docs/superpowers/specs/2026-10-14-pcb-design-kicad-design.md`

## Global Constraints

- Python in `hardware/` runs under KiCad's bundled Python **3.9** (no `match`, no `X | Y` type unions, no pip packages). Tests use `unittest`.
- **No Java on the Mac.** Freerouting runs only as `ghcr.io/freerouting/freerouting:2.5.0` in Docker.
- Generated files are deterministic: UUIDs from `uuid.uuid5(NAMESPACE, "dryer/<key>")`, dictionaries emitted in sorted order, no timestamps.
- Mains nets are exactly `L_IN`, `L_FUSED`, `L_SW_A`, `L_SW_B`, `N`; they form netclass `MAINS` (1.5 mm tracks, 1.0 mm in-class clearance, no pours). Mains to any other net: 6 mm, relaxed to 3.5 mm only inside rule areas named `relay_pads`. Copper to edge and slot 0.5 mm; mains copper to edge 1 mm.
- Relay K1/K2: pad 1 = COM, pads 2 and 5 = coil, **pad 3 = NO** (heater), **pad 4 = NC** (no copper). Derived from the KiCad `SANYOU_SRD_Form_C` symbol drawing and Songle's wiring diagram; the first-article continuity check confirms it on the real part.
- The pin map by header position is fixed (spec, `pinmap.py`); 12-pin positions 9 and 10 and 16-pin positions 15 and 16 stay unconnected; I2C stays on the ESP's Qwiic connector.
- Part choices: every part carries an LCSC number or `hand_fit=True`; no part is "tested" or "verified" in docs unless it was.
- Repo rules: no device IPs, no VMD-08/Azco branding in titles, numbers sourced from `docs/datasheets/`, unverified values marked as such.
- Commit after every task with a message in the repo's style (imperative, what and why); end commit messages with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Never `cp` onto `esphome/secrets.yaml` in a worktree (it is a symlink to the real secrets).

## Review Focus

1. **A footprint whose pad numbers do not match the symbol's pin numbers** (the slide switch and fuse holder are the likely ones): the part would be wired to the wrong pads. Task 5's test asserts every footprint has every pad number the model assigns.
2. **Relay NO/NC swapped**: the heater would be live with the relay off. Task 3's test pins K1/K2 pad 3 to `L_SW_x` and pad 4 to NC, and Task 17's continuity check confirms it on the real relay.
3. **A mains net left out of the `MAINS` netclass pattern** (`N` does not match `L_*`): the 6 mm rule would silently not apply. Task 8's test asserts each of the five mains nets resolves to `MAINS` and no other net does.
4. **Copper under the antenna**: a track or pour routed into the keep-out would detune the WiFi antenna. Task 10's test scans the routed board for any copper inside the antenna rectangle.
5. **Electrolytic or LED polarity reversed in the model**: a reversed 100 µF at 24 V vents. Task 3's test asserts pad 1 of every `C_Polarized` is on a rail and pad 2 on GND, and that every LED's anode side goes to its resistor and its cathode to the switched node or GND.

# hardware/dryer_board/kicad_env.py
"""Where KiCad lives. macOS app bundle first, then the kicad/kicad Docker image layout,
then anything on PATH. Override with KICAD_CLI, KICAD_SYMBOL_DIR, KICAD_FOOTPRINT_DIR."""
import os, shutil, subprocess

HERE = os.path.dirname(os.path.abspath(__file__))
REPO = os.path.abspath(os.path.join(HERE, "..", ".."))
PROJECT_DIR = os.path.join(REPO, "hardware", "dryer-controller")
OUT_DIR = os.path.join(REPO, "hardware", "out")
PROJECT = "dryer-controller"

_MAC_APP = "/Applications/KiCad/KiCad.app/Contents"
_CANDIDATES = {
    "cli": [os.environ.get("KICAD_CLI", ""), _MAC_APP + "/MacOS/kicad-cli", "/usr/bin/kicad-cli"],
    "symbols": [os.environ.get("KICAD_SYMBOL_DIR", ""), _MAC_APP + "/SharedSupport/symbols", "/usr/share/kicad/symbols"],
    "footprints": [os.environ.get("KICAD_FOOTPRINT_DIR", ""), _MAC_APP + "/SharedSupport/footprints", "/usr/share/kicad/footprints"],
}

def _first(kind, test):
    for c in _CANDIDATES[kind]:
        if c and test(c):
            return c
    found = shutil.which("kicad-cli") if kind == "cli" else None
    if found:
        return found
    raise FileNotFoundError("KiCad %s not found; set KICAD_CLI / KICAD_SYMBOL_DIR / KICAD_FOOTPRINT_DIR" % kind)

def kicad_cli():
    return _first("cli", os.path.isfile)

def symbol_dir():
    return _first("symbols", os.path.isdir)

def footprint_dir():
    return _first("footprints", os.path.isdir)

def run_cli(*args, cwd=None):
    """Run kicad-cli with args; raise with stdout+stderr on failure."""
    proc = subprocess.run([kicad_cli(), *args], cwd=cwd, capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError("kicad-cli %s failed (%d):\n%s\n%s" % (" ".join(args), proc.returncode, proc.stdout, proc.stderr))
    return proc
```

# hardware/dryer_board/sexp.py
"""Minimal S-expression support for KiCad files. Quoted strings parse to Str so they
are written back quoted; bare tokens stay str."""
import re

class Str(str):
    """A token that was (and must be) double-quoted."""

_TOKEN = re.compile(r'\(|\)|"(?:[^"\\]|\\.)*"|[^\s()"]+')

def _unescape(s):
    return s.replace('\\"', '"').replace("\\\\", "\\")

def _escape(s):
    return s.replace("\\", "\\\\").replace('"', '\\"')

def parse(text):
    stack = [[]]
    for tok in _TOKEN.findall(text):
        if tok == "(":
            stack.append([])
        elif tok == ")":
            done = stack.pop()
            stack[-1].append(done)
        elif tok.startswith('"'):
            stack[-1].append(Str(_unescape(tok[1:-1])))
        else:
            stack[-1].append(tok)
    if len(stack) != 1 or len(stack[0]) != 1:
        raise ValueError("unbalanced S-expression")
    return stack[0][0]

def _atom(a):
    if isinstance(a, Str):
        return '"%s"' % _escape(a)
    return a

def dump(node, indent=0):
    """indent=None gives one line; an int gives KiCad-like one-child-per-line output."""
    if not isinstance(node, list):
        return _atom(node)
    if indent is None or not any(isinstance(c, list) for c in node):
        return "(" + " ".join(dump(c, None) for c in node) + ")"
    pad = "\t" * (indent + 1)
    head = [dump(c, None) for c in node if not isinstance(c, list)]
    kids = [pad + dump(c, indent + 1) for c in node if isinstance(c, list)]
    return "(" + " ".join(head) + "\n" + "\n".join(kids) + "\n" + "\t" * indent + ")"

def find(node, key):
    for c in node:
        if isinstance(c, list) and c and c[0] == key:
            return c
    return None

def find_all(node, key):
    return [c for c in node if isinstance(c, list) and c and c[0] == key]
```

#!/usr/bin/env python3
"""The main board is wired by header position; each board package names the GPIO behind
each position. This holds the two against each other so neither can drift. Plain python3,
no PyYAML: the substitutions are parsed with a regex."""
import os, re, sys, unittest

REPO = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, os.path.join(REPO, "hardware"))
from dryer_board import pinmap  # noqa: E402

def substitutions(path):
    """pin_* -> GPIO number from a board package. Handles `pin_x: GPIO8` and the nested
    `pin_x:\n    number: GPIO8` form."""
    text = open(path, encoding="utf-8").read()
    out = {}
    for m in re.finditer(r"^  (pin_\w+):(?:[ \t]+GPIO(\d+)|\s*\n\s+number:\s*GPIO(\d+))", text, re.M):
        out[m.group(1)] = int(m.group(2) or m.group(3))
    return out

class PinMap(unittest.TestCase):
    def check(self, board, path):
        subs = substitutions(path)
        for sub, fn in pinmap.SUBSTITUTIONS.items():
            self.assertIn(sub, subs, "%s missing from %s" % (sub, path))
            pos = pinmap.FUNCTIONS[fn]
            self.assertEqual(subs[sub], pinmap.POSITION_GPIO[board][pos],
                             "%s: %s is GPIO%d but position %s carries GPIO%d" % (board, sub, subs[sub], pos, pinmap.POSITION_GPIO[board][pos]))
        self.assertEqual(set(subs), set(pinmap.SUBSTITUTIONS), "substitution list changed; update pinmap.py")

    def test_s2(self):
        self.check("s2", os.path.join(REPO, "esphome", "packages", "board-s2.yaml"))

    def test_c6(self):
        self.check("c6", os.path.join(REPO, "esphome", "packages", "board-c6.yaml"))

    def test_reserved_positions_have_no_function(self):
        for pos in pinmap.RESERVED:
            self.assertNotIn(pos, pinmap.FUNCTIONS.values())

if __name__ == "__main__":
    unittest.main()

# hardware/dryer_board/libs.py
"""Read KiCad's stock symbol and footprint libraries. A derived symbol (`extends`) is
flattened the way KiCad embeds it in a schematic: the parent's drawing and pins with the
child's properties, units renamed to the child's name."""
import os, functools
from . import sexp, kicad_env

def split(lib_id):
    lib, name = lib_id.split(":", 1)
    return lib, name

@functools.lru_cache(maxsize=None)
def _library(lib):
    path = os.path.join(kicad_env.symbol_dir(), lib + ".kicad_sym")
    return sexp.parse(open(path, encoding="utf-8").read())

def _raw_symbol(lib, name):
    for node in _library(lib)[1:]:
        if isinstance(node, list) and node and node[0] == "symbol" and node[1] == name:
            return node
    raise KeyError("symbol %s:%s not in the stock libraries" % (lib, name))

def load_symbol(lib_id):
    lib, name = split(lib_id)
    sym = list(_raw_symbol(lib, name))
    ext = sexp.find(sym, "extends")
    if ext:
        parent_name = ext[1]
        parent = list(_raw_symbol(lib, parent_name))
        child_props = {p[1]: p for p in sexp.find_all(sym, "property")}
        merged = []
        seen = set()
        for node in parent:
            if isinstance(node, list) and node and node[0] == "property":
                merged.append(child_props.get(node[1], node)); seen.add(node[1])
            elif isinstance(node, list) and node and node[0] == "symbol":
                unit = list(node); unit[1] = sexp.Str(name + node[1][len(parent_name):]); merged.append(unit)
            else:
                merged.append(node)
        extra = [p for k, p in child_props.items() if k not in seen]
        sym = merged[:2] + extra + merged[2:]
    sym[1] = sexp.Str(lib_id)
    return sym

def symbol_pins(lib_id):
    out = {}
    for unit in sexp.find_all(load_symbol(lib_id), "symbol"):
        for pin in sexp.find_all(unit, "pin"):
            at = sexp.find(pin, "at")
            number = sexp.find(pin, "number")[1]
            out[number] = (float(at[1]), float(at[2]), int(float(at[3])), pin[1])
    return out

def footprint_path(lib_id):
    lib, name = split(lib_id)
    if lib == "dryer":
        base = os.path.join(kicad_env.PROJECT_DIR, "lib", "dryer.pretty")
    else:
        base = os.path.join(kicad_env.footprint_dir(), lib + ".pretty")
    if not os.path.isfile(os.path.join(base, name + ".kicad_mod")):
        raise FileNotFoundError("footprint %s not found under %s" % (lib_id, base))
    return base

@functools.lru_cache(maxsize=None)
def _footprint(lib_id):
    base = footprint_path(lib_id)
    return sexp.parse(open(os.path.join(base, split(lib_id)[1] + ".kicad_mod"), encoding="utf-8").read())

def footprint_pad_positions(lib_id):
    """pad number -> (x, y) mm in the footprint's frame (KiCad: y down). Unnumbered pads are skipped."""
    out = {}
    for pad in sexp.find_all(_footprint(lib_id), "pad"):
        if pad[1] == "":
            continue
        at = sexp.find(pad, "at")
        out[pad[1]] = (float(at[1]), float(at[2]))
    return out

def footprint_pads(lib_id):
    return set(footprint_pad_positions(lib_id))
```

# hardware/dryer_board/schematic.py
"""Write the schematic as a net-label grid: every symbol in its own cell, a global label on
every pin. KiCad 8 file format (version 20231120), which KiCad 10 reads."""
import os, re, uuid
from . import circuit, libs, sexp, kicad_env

NAMESPACE = uuid.uuid5(uuid.NAMESPACE_URL, "https://github.com/jrytio/desiccant-dryer/hardware")
CELL = 38.1
COLS = 10
ORIGIN = 25.4
ROOT = None  # set in write()

def uuid_for(key):
    return str(uuid.uuid5(NAMESPACE, "dryer/" + key))

def _q(s):
    return '"%s"' % str(s).replace("\\", "\\\\").replace('"', '\\"')

def _prop(name, value, x, y, hide=False, size=1.27):
    h = " (hide yes)" if hide else ""
    return '(property %s %s (at %.2f %.2f 0) (effects (font (size %s %s))%s))' % (_q(name), _q(value), x, y, size, size, h)

def _symbol_instance(part, cx, cy):
    props = [_prop("Reference", part.ref, cx, cy - 2.54), _prop("Value", part.value, cx, cy + 2.54),
             _prop("Footprint", part.footprint, cx, cy, hide=True), _prop("Datasheet", "~", cx, cy, hide=True),
             _prop("LCSC", part.lcsc, cx, cy, hide=True), _prop("Description", part.description, cx, cy, hide=True)]
    if part.hand_fit:
        props.append(_prop("Hand fit", "yes", cx, cy, hide=True))
    pins = " ".join('(pin %s (uuid %s))' % (_q(n), _q(uuid_for(part.ref + "/pin/" + n))) for n in sorted(libs.symbol_pins(part.symbol)))
    in_bom = "no" if part.ref.startswith("#") else "yes"
    return ('(symbol (lib_id %s) (at %.2f %.2f 0) (unit 1) (exclude_from_sim no) (in_bom %s) (on_board yes) (dnp no) (uuid %s) %s %s '
            '(instances (project %s (path %s (reference %s) (unit 1)))))'
            % (_q(part.symbol), cx, cy, in_bom, _q(uuid_for(part.ref)), " ".join(props), pins,
               _q(circuit.PROJECT), _q("/" + ROOT), _q(part.ref)))

_LABEL_ANGLE = {0: 180, 180: 0, 90: 270, 270: 90}

def _label(net, x, y, angle, key):
    return ('(global_label %s (shape input) (at %.2f %.2f %d) (effects (font (size 1.27 1.27)) (justify left)) (uuid %s))'
            % (_q(net), x, y, angle, _q(uuid_for("label/" + key))))

def _no_connect(x, y, key):
    return '(no_connect (at %.2f %.2f) (uuid %s))' % (x, y, _q(uuid_for("nc/" + key)))

def _cell(i):
    return ORIGIN + (i % COLS) * CELL, ORIGIN + (i // COLS) * CELL

def write(project_dir):
    global ROOT
    ROOT = uuid_for("root")
    body, embedded, seen = [], [], set()
    for i, part in enumerate(circuit.PARTS):
        cx, cy = _cell(i)
        if part.symbol not in seen:
            seen.add(part.symbol); embedded.append(sexp.dump(libs.load_symbol(part.symbol), indent=None))
        body.append(_symbol_instance(part, cx, cy))
        pins = libs.symbol_pins(part.symbol)
        for number, (px, py, angle, _etype) in sorted(pins.items()):
            x, y = cx + px, cy - py
            net = part.pins.get(number, circuit.NC)
            key = part.ref + "/" + number
            if net == circuit.NC:
                body.append(_no_connect(x, y, key))
            else:
                body.append(_label(net, x, y, _LABEL_ANGLE[angle % 360], key))
    doc = ('(kicad_sch (version 20231120) (generator "dryer_board") (generator_version "1.0") (uuid %s) (paper "A2")\n'
           '(title_block (title %s) (rev %s) (company "AGPL-3.0, github.com/jrytio/desiccant-dryer"))\n'
           '(lib_symbols %s)\n%s\n(sheet_instances (path "/" (page "1"))))\n'
           % (_q(ROOT), _q(circuit.TITLE), _q(circuit.REVISION), "\n".join(embedded), "\n".join(body)))
    path = os.path.join(project_dir, circuit.PROJECT + ".kicad_sch")
    with open(path, "w", encoding="utf-8") as f:
        f.write(doc)
    return path

def write_lib_tables(project_dir):
    """Project-local tables for the stock libraries the parts use, plus the local footprint
    library. kicad-cli has no global tables in CI, so these are required for ERC and DRC."""
    sym_libs = sorted({libs.split(p.symbol)[0] for p in circuit.PARTS})
    fp_libs = sorted({libs.split(p.footprint)[0] for p in circuit.PARTS if p.footprint and not p.footprint.startswith("dryer:")})
    with open(os.path.join(project_dir, "sym-lib-table"), "w") as f:
        f.write("(sym_lib_table (version 7)\n")
        for lib in sym_libs:
            f.write('  (lib (name "%s") (type "KiCad") (uri "${KICAD10_SYMBOL_DIR}/%s.kicad_sym") (options "") (descr ""))\n' % (lib, lib))
        f.write(")\n")
    with open(os.path.join(project_dir, "fp-lib-table"), "w") as f:
        f.write("(fp_lib_table (version 7)\n")
        for lib in fp_libs:
            f.write('  (lib (name "%s") (type "KiCad") (uri "${KICAD10_FOOTPRINT_DIR}/%s.pretty") (options "") (descr ""))\n' % (lib, lib))
        f.write('  (lib (name "dryer") (type "KiCad") (uri "${KIPRJMOD}/lib/dryer.pretty") (options "") (descr "local footprints"))\n')
        f.write(")\n")
    os.makedirs(os.path.join(project_dir, "lib", "dryer.pretty"), exist_ok=True)

def netlist_from_kicad(sch_path):
    out_path = sch_path + ".net"
    kicad_env.run_cli("sch", "export", "netlist", "--format", "kicadsexpr", "-o", out_path, sch_path)
    tree = sexp.parse(open(out_path, encoding="utf-8").read())
    nets = {}
    for net in sexp.find_all(sexp.find(tree, "nets"), "net"):
        name = sexp.find(net, "name")[1]
        nodes = {(sexp.find(n, "ref")[1], sexp.find(n, "pin")[1]) for n in sexp.find_all(net, "node")}
        nodes = {(r, p) for r, p in nodes if not r.startswith("#")}
        if len(nodes) > 1:
            nets[name] = nodes
    return nets
```

# hardware/dryer_board/project.py
"""The KiCad project file (netclasses, DRC severities, board rules) and the custom DRC rules.
Net settings use the schema KiCad 10 writes (net_settings meta version 5); an older or
sparser schema is silently ignored by kicad-cli, which is how a rule can fail to apply."""
import json, os
from . import circuit

RULES = """(version 1)
(rule "mains track width"
  (condition "A.NetClass == 'MAINS'")
  (constraint track_width (min 1.5mm)))
(rule "mains to board edge"
  (condition "A.NetClass == 'MAINS'")
  (constraint edge_clearance (min 1mm)))
(rule "mains to selv"
  (condition "A.NetClass == 'MAINS' && B.NetClass != 'MAINS'")
  (constraint clearance (min 6mm)))
(rule "mains to selv at relay pads"
  (condition "A.NetClass == 'MAINS' && B.NetClass != 'MAINS' && A.insideArea('relay_pads')")
  (constraint clearance (min 3.5mm)))
"""

def _class(name, track, clearance, via, drill, priority):
    return {"bus_width": 12, "clearance": clearance, "diff_pair_gap": 0.25, "diff_pair_via_gap": 0.25,
            "diff_pair_width": 0.2, "line_style": 0, "microvia_diameter": 0.3, "microvia_drill": 0.1,
            "name": name, "pcb_color": "rgba(0, 0, 0, 0.000)", "priority": priority,
            "schematic_color": "rgba(0, 0, 0, 0.000)", "track_width": track, "via_diameter": via,
            "via_drill": drill, "wire_width": 6}

def netclass_patterns():
    out = []
    for name, (_t, _c, _v, _d, patterns) in circuit.NETCLASSES.items():
        for p in patterns:
            out.append((p, name))
    return out

def project_dict():
    classes = []
    for i, (name, (track, clearance, via, drill, _p)) in enumerate(circuit.NETCLASSES.items()):
        classes.append(_class(name, track, clearance, via, drill, 2147483647 if name == "Default" else i))
    return {
        "board": {"design_settings": {
            "rules": {"min_clearance": 0.2, "min_track_width": 0.2, "min_copper_edge_clearance": 0.5,
                      "min_via_diameter": 0.6, "min_via_annular_width": 0.15, "min_through_hole_diameter": 0.3,
                      "min_hole_clearance": 0.25, "min_hole_to_hole": 0.5, "min_silk_clearance": 0.0},
            # Silk-over-pad and silk-overlap are cosmetic and the fab clips silk on pads;
            # ignoring them keeps "DRC clean" about copper, clearance and connectivity.
            "rule_severities": {"track_dangling": "warning", "via_dangling": "warning",
                                "silk_overlap": "ignore", "silk_over_copper": "ignore",
                                "silk_edge_clearance": "ignore", "lib_footprint_issues": "ignore",
                                "lib_footprint_mismatch": "ignore"}}},
        "meta": {"filename": circuit.PROJECT + ".kicad_pro", "version": 3},
        "net_settings": {"classes": classes, "meta": {"version": 5}, "net_colors": None,
                         "netclass_assignments": None,
                         "netclass_patterns": [{"netclass": c, "pattern": p} for p, c in netclass_patterns()]},
        "text_variables": {"REVISION": circuit.REVISION},
    }

def write(project_dir):
    with open(os.path.join(project_dir, circuit.PROJECT + ".kicad_pro"), "w") as f:
        json.dump(project_dict(), f, indent=2, sort_keys=True)
        f.write("\n")
    with open(os.path.join(project_dir, circuit.PROJECT + ".kicad_dru"), "w") as f:
        f.write(RULES)

# hardware/dryer_board/board.py
"""Build or update the .kicad_pcb with pcbnew. The generator owns footprints, nets, outline,
zones, rule areas and text; tracks and vias survive a rebuild unless their net left the
model or fresh=True."""
import os, subprocess
import pcbnew
from . import circuit, libs, placement, kicad_env

MM = pcbnew.VECTOR2I_MM
def mm(v): return pcbnew.FromMM(v)

_JUSTIFY = {"left": pcbnew.GR_TEXT_H_ALIGN_LEFT, "right": pcbnew.GR_TEXT_H_ALIGN_RIGHT, "center": pcbnew.GR_TEXT_H_ALIGN_CENTER}
_LAYER = {"F.SilkS": pcbnew.F_SilkS, "B.SilkS": pcbnew.B_SilkS}

def _rect(b, layer, x1, y1, x2, y2, width=0.1):
    s = pcbnew.PCB_SHAPE(b); s.SetShape(pcbnew.SHAPE_T_RECT)
    s.SetStart(MM(x1, y1)); s.SetEnd(MM(x2, y2)); s.SetLayer(layer); s.SetWidth(mm(width)); b.Add(s)

def _segment(b, layer, x1, y1, x2, y2, width=0.3):
    s = pcbnew.PCB_SHAPE(b); s.SetShape(pcbnew.SHAPE_T_SEGMENT)
    s.SetStart(MM(x1, y1)); s.SetEnd(MM(x2, y2)); s.SetLayer(layer); s.SetWidth(mm(width)); b.Add(s)

def _poly(b, layer, pts, width=0.1):
    s = pcbnew.PCB_SHAPE(b); s.SetShape(pcbnew.SHAPE_T_POLY)
    sps = pcbnew.SHAPE_POLY_SET(); sps.NewOutline()
    for x, y in pts:
        sps.Append(MM(x, y))
    s.SetPolyShape(sps); s.SetLayer(layer); s.SetWidth(mm(width)); s.SetFilled(False); b.Add(s)

def _zone_outline(z, x1, y1, x2, y2):
    o = z.Outline(); o.NewOutline()
    for x, y in ((x1, y1), (x2, y1), (x2, y2), (x1, y2)):
        o.Append(MM(x, y))

def _rule_area(b, name, rect, fills=True, tracks=False, vias=False, pads=False):
    z = pcbnew.ZONE(b); z.SetIsRuleArea(True); z.SetZoneName(name); z.SetLayerSet(pcbnew.LSET.AllCuMask(2))
    z.SetDoNotAllowZoneFills(fills); z.SetDoNotAllowTracks(tracks); z.SetDoNotAllowVias(vias)
    z.SetDoNotAllowPads(pads); z.SetDoNotAllowFootprints(False)
    _zone_outline(z, *rect); b.Add(z)

def _pour(b, layer, net, rect):
    z = pcbnew.ZONE(b); z.SetLayer(layer); z.SetNet(net); z.SetZoneName("gnd_" + ("F" if layer == pcbnew.F_Cu else "B"))
    z.SetLocalClearance(mm(0.3)); z.SetMinThickness(mm(0.25)); z.SetPadConnection(pcbnew.ZONE_CONNECTION_THERMAL)
    _zone_outline(z, *rect); b.Add(z)

def _text(b, text, x, y, size, rot, layer, justify):
    t = pcbnew.PCB_TEXT(b); t.SetText(text); t.SetPosition(MM(x, y)); t.SetLayer(_LAYER[layer])
    t.SetTextSize(MM(size, size)); t.SetTextThickness(mm(max(0.12, size * 0.15)))
    t.SetHorizJustify(_JUSTIFY[justify]); t.SetTextAngleDegrees(rot)
    if layer == "B.SilkS":
        t.SetMirrored(True)
    b.Add(t)

def _clear_generated(b):
    """Remove everything the generator owns: shapes, zones, text. Footprints are reconciled
    separately; tracks are kept."""
    for item in list(b.GetDrawings()):
        b.Remove(item)
    for z in list(b.Zones()):
        b.Remove(z)

def _net(b, name):
    net = b.FindNet(name)
    if net is None:
        net = pcbnew.NETINFO_ITEM(b, name); b.Add(net)
    return net

def _reconcile_footprints(b):
    existing = {f.GetReference(): f for f in b.GetFootprints()}
    for ref, fp in existing.items():
        part = next((p for p in circuit.board_parts() if p.ref == ref), None)
        if part is None or str(fp.GetFPID().Format()) != part.footprint:
            b.Remove(fp)
    for part in circuit.board_parts():
        fp = b.FindFootprintByReference(part.ref)
        if fp is None:
            fp = pcbnew.FootprintLoad(libs.footprint_path(part.footprint), libs.split(part.footprint)[1])
            fp.SetFPIDAsString(part.footprint); fp.SetReference(part.ref); b.Add(fp)
        fp.SetValue(part.value)
        x, y, rot = placement.PLACE[part.ref]
        fp.SetOrientationDegrees(0); fp.SetPosition(MM(x, y)); fp.SetOrientationDegrees(rot)
        for pad in fp.Pads():
            net = part.pins.get(pad.GetNumber(), circuit.NC)
            if net == circuit.NC:
                pad.SetNetCode(0)
            else:
                pad.SetNet(_net(b, net))

def apply_netclasses(b):
    ns = b.GetDesignSettings().m_NetSettings
    for name, (track, clearance, via, drill, patterns) in circuit.NETCLASSES.items():
        if name == "Default":
            continue
        nc = pcbnew.NETCLASS(name)
        nc.SetTrackWidth(mm(track)); nc.SetClearance(mm(clearance)); nc.SetViaDiameter(mm(via)); nc.SetViaDrill(mm(drill))
        ns.SetNetclass(name, nc)
        for p in patterns:
            ns.SetNetclassPatternAssignment(p, name)
    b.SynchronizeNetsAndNetClasses(False)

def _drop_orphan_tracks(b):
    names = set(circuit.nets())
    for t in list(b.GetTracks()):
        if t.GetNetname() not in names:
            b.Remove(t)

def build(pcb_path, fresh=False):
    if os.path.exists(pcb_path) and not fresh:
        b = pcbnew.LoadBoard(pcb_path)
        _clear_generated(b)
    else:
        b = pcbnew.BOARD()
    for name in circuit.nets():
        _net(b, name)
    _reconcile_footprints(b)
    if fresh:
        for t in list(b.GetTracks()):
            b.Remove(t)
    else:
        _drop_orphan_tracks(b)
    # outline and slot
    _rect(b, pcbnew.Edge_Cuts, 0, 0, placement.BOARD_W, placement.BOARD_H)
    x1, x2 = placement.SLOT_X
    for y1, y2 in placement.SLOT_SEGMENTS:
        _poly(b, pcbnew.Edge_Cuts, [(x1, y1), (x2, y1), (x2, y2), (x1, y2)])
    # rule areas and pours
    _rule_area(b, "antenna_keepout", placement.ANTENNA_KEEPOUT, fills=True, tracks=True, vias=True, pads=True)
    _rule_area(b, "mains_nopour", placement.MAINS_ZONE, fills=True)
    for r in placement.RELAY_AREAS:
        _rule_area(b, "relay_pads", r, fills=False)
    gnd = _net(b, "GND")
    _pour(b, pcbnew.F_Cu, gnd, placement.SELV_POUR)
    _pour(b, pcbnew.B_Cu, gnd, placement.SELV_POUR)
    # silkscreen
    for text, x, y, size, rot, layer, justify in placement.SILK:
        _text(b, text.replace("${REVISION}", circuit.REVISION), x, y, size, rot, layer, justify)
    _segment(b, pcbnew.F_SilkS, 73.5, 3, 73.5, 82)
    apply_netclasses(b)
    pcbnew.ZONE_FILLER(b).Fill(b.Zones())
    pcbnew.SaveBoard(pcb_path, b)
    return b

def export_dsn(b, dsn_path):
    if not pcbnew.ExportSpecctraDSN(b, dsn_path):
        raise RuntimeError("DSN export failed")
    return dsn_path

def drc_report(pcb_path):
    """Run DRC and return the report text. kicad-cli exits 5 on violations, so this does
    not go through run_cli."""
    rpt = pcb_path + ".drc.rpt"
    subprocess.run([kicad_env.kicad_cli(), "pcb", "drc", "--severity-all", "--refill-zones", "-o", rpt, pcb_path],
                   capture_output=True, text=True)
    return open(rpt).read()

"""Autoroute with Freerouting running in Docker (no Java on the host). Routing is not
deterministic; the routed board is committed and CI never routes."""
import os, subprocess, shutil
import pcbnew

IMAGE = "ghcr.io/freerouting/freerouting:2.5.0"

def run_freerouting(dsn_path, ses_path, passes=50):
    work = os.path.dirname(os.path.abspath(dsn_path))
    os.makedirs(os.path.join(work, ".freerouting"), exist_ok=True)
    cmd = ["docker", "run", "--rm", "-u", "%d:%d" % (os.getuid(), os.getgid()),
           "-v", work + ":/work", IMAGE,
           "java", "-jar", "/app/freerouting-executable.jar",
           "--user_data_path=/work/.freerouting", "--gui-enabled=false",
           "-de", "/work/" + os.path.basename(dsn_path), "-do", "/work/" + os.path.basename(ses_path),
           "-mp", str(passes), "-mt", "4"]
    proc = subprocess.run(cmd, capture_output=True, text=True)
    if not os.path.isfile(ses_path):
        raise RuntimeError("Freerouting produced no SES:\n%s\n%s" % (proc.stdout[-3000:], proc.stderr[-3000:]))
    shutil.rmtree(os.path.join(work, ".freerouting"), ignore_errors=True)

def route(pcb_path, passes=50):
    b = pcbnew.LoadBoard(pcb_path)
    from . import board as board_mod
    board_mod.apply_netclasses(b)
    dsn = pcb_path[:-len(".kicad_pcb")] + ".dsn"
    ses = pcb_path[:-len(".kicad_pcb")] + ".ses"
    for p in (dsn, ses):
        if os.path.exists(p):
            os.remove(p)
    board_mod.export_dsn(b, dsn)
    run_freerouting(dsn, ses, passes)
    if not pcbnew.ImportSpecctraSES(b, ses):
        raise RuntimeError("SES import failed")
    pcbnew.ZONE_FILLER(b).Fill(b.Zones())
    pcbnew.SaveBoard(pcb_path, b)
    for p in (dsn, ses):
        os.remove(p)
    return len(list(b.GetTracks()))

# hardware/dryer_board/check_sync.py
"""Is the committed KiCad project what the model would generate? Compared semantically
(netlists, footprints, pad nets, positions, rules), not byte for byte, so a GUI re-save that
changes only formatting still passes."""
import json, os, tempfile
import pcbnew
from . import circuit, placement, project, schematic

def schematic_diffs(project_dir):
    diffs = []
    tmp = tempfile.mkdtemp()
    schematic.write_lib_tables(tmp); schematic.write(tmp); project.write(tmp)
    committed = os.path.join(project_dir, circuit.PROJECT + ".kicad_sch")
    if not os.path.exists(committed):
        return ["%s missing" % committed]
    want = schematic.netlist_from_kicad(os.path.join(tmp, circuit.PROJECT + ".kicad_sch"))
    got = schematic.netlist_from_kicad(committed)
    for net in sorted(set(want) | set(got)):
        if want.get(net) != got.get(net):
            diffs.append("schematic net %s: model %s, committed %s" % (net, sorted(want.get(net, [])), sorted(got.get(net, []))))
    for name in (circuit.PROJECT + ".kicad_dru", "sym-lib-table", "fp-lib-table"):
        if open(os.path.join(tmp, name)).read() != open(os.path.join(project_dir, name)).read():
            diffs.append("%s differs from the generator's output" % name)
    pro = circuit.PROJECT + ".kicad_pro"
    if json.load(open(os.path.join(tmp, pro))) != json.load(open(os.path.join(project_dir, pro))):
        diffs.append("%s differs from the generator's output" % pro)
    return diffs

def board_diffs(pcb_path):
    diffs = []
    if not os.path.exists(pcb_path):
        return ["%s missing" % pcb_path]
    b = pcbnew.LoadBoard(pcb_path)
    have = {f.GetReference(): f for f in b.GetFootprints()}
    for part in circuit.board_parts():
        fp = have.pop(part.ref, None)
        if fp is None:
            diffs.append("%s missing from the board" % part.ref); continue
        if str(fp.GetFPID().Format()) != part.footprint:
            diffs.append("%s footprint %s, model %s" % (part.ref, fp.GetFPID().Format(), part.footprint))
        x, y, rot = placement.PLACE[part.ref]
        px, py = fp.GetPosition().x / 1e6, fp.GetPosition().y / 1e6
        if abs(px - x) > 0.01 or abs(py - y) > 0.01 or (fp.GetOrientationDegrees() - rot) % 360 > 0.01:
            diffs.append("%s at (%.2f, %.2f, %.0f), model (%.2f, %.2f, %d)" % (part.ref, px, py, fp.GetOrientationDegrees(), x, y, rot))
        for pad in fp.Pads():
            want = part.pins.get(pad.GetNumber(), circuit.NC)
            got = pad.GetNetname() or circuit.NC
            if want != got:
                diffs.append("%s pad %s on %s, model %s" % (part.ref, pad.GetNumber(), got, want))
    for ref in have:
        diffs.append("%s on the board but not in the model" % ref)
    names = sorted(z.GetZoneName() for z in b.Zones() if z.GetIsRuleArea())
    if names != ["antenna_keepout", "mains_nopour", "relay_pads", "relay_pads"]:
        diffs.append("rule areas %s" % names)
    return diffs

def all_diffs(project_dir):
    return schematic_diffs(project_dir) + board_diffs(os.path.join(project_dir, circuit.PROJECT + ".kicad_pcb"))

def jlc_cpl(kicad_csv, out_csv):
    """KiCad position CSV -> JLCPCB CPL. Mounting holes and test points carry no part, so
    rows without a package in the BOM sense are kept anyway: JLCPCB ignores designators
    absent from the BOM. Rotation is KiCad's; JLCPCB's viewer is where any per-footprint
    offset (SOT-23, SMA) is corrected before ordering."""
    with open(kicad_csv) as f, open(out_csv, "w", newline="") as g:
        r = csv.DictReader(f); w = csv.writer(g)
        w.writerow(["Designator", "Mid X", "Mid Y", "Layer", "Rotation"])
        for row in r:
            if row["Ref"].startswith(("H", "TP")):
                continue
            w.writerow([row["Ref"], row["PosX"], row["PosY"], "Top" if row["Side"] == "top" else "Bottom", row["Rot"]])

name: hardware

on:
  push:
    branches: [main]
    tags: ['pcb-*']
    paths: ['hardware/**', 'scripts/hardware.sh', 'tests/test_pinmap.py', '.github/workflows/hardware.yml']
  pull_request:
    paths: ['hardware/**', 'scripts/hardware.sh', 'tests/test_pinmap.py', '.github/workflows/hardware.yml']

# The committed KiCad files are checked against the generator, then ERC, DRC and the fab
# exports run with the same KiCad version as the desktop. Routing never runs here: it is
# not deterministic, so the routed board is committed.
jobs:
  check:
    name: kicad check and export
    runs-on: ubuntu-latest
    container:
      image: kicad/kicad:10.0
      options: --user root
    steps:
      - uses: actions/checkout@v7
      - name: Hold the firmware pin map against the hardware pin map
        run: python3 tests/test_pinmap.py
      - name: Unit tests
        run: scripts/hardware.sh test
      - name: Generator sync, ERC, DRC
        run: scripts/hardware.sh check
      - name: Fab exports and renders
        run: scripts/hardware.sh export
      - uses: actions/upload-artifact@v4
        with:
          name: hardware-outputs
          path: hardware/out
  release:
    name: pcb release
    if: startsWith(github.ref, 'refs/tags/pcb-')
    needs: check
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: hardware-outputs
          path: out
      - name: Create the release with the fab files

          GH_TOKEN: ${{ github.token }}
